# 🔮 D&D 5e Character Sheet — Рефакторинг

Локальный лист персонажа D&D 5e, реализованный на чистом JavaScript с лёгким Node.js сервером, базой заклинаний и поддержкой русской/английской локализации.

**Текущая версия:** `1.0.8.4`

## 🚀 Запуск
Проект запускается из корня через `START.bat` или командой:

```bash
npm start
```

Сервер поднимается на `http://localhost:3000`, после чего приложение доступно в браузере. Сейчас требуется сервер для работы API и загрузки базы заклинаний.


## 🗄️ Backend и SQLite

Для работы с базой данных добавлен минимальный Node-сервер.

- Файл сервера: `server.js`
- Модели: `models/database.js`
- Путь к базе: `data/database.sqlite`

Запуск сервера:

```bash
npm start
```

После запуска можно обращаться к API:

- `GET /api/status`
- `GET /api/characters`
- `POST /api/characters`
- `GET /api/spells`
- `GET /api/races`
- `GET /api/classes`

Статические файлы доступны по адресу `http://localhost:3000/`.

## 🔧 Возможные проблемы и решения

### Проблема 1: "Функция X не найдена"
**Причина:** Нарушен порядок подключения скриптов в `index.html`.
**Решение:** Убедитесь, что скрипт, вызывающий функцию, подключён ПОСЛЕ скрипта, где она объявлена.

### Проблема 2: "state is not defined"
**Причина:** `state.js` подключён после скрипта, который его использует.
**Решение:** `state.js` должен быть подключён ВТОРЫМ (после `utils.js`).

### Проблема 3: Классовые ресурсы не отображаются
**Причина:** `class-resources.js` подключён до `multiclass.js` или `ui-core.js`.
**Решение:** Проверьте порядок: `multiclass.js` → `class-resources.js` (после `spells.js`).

### Проблема 4: Обработчики событий не работают
**Причина:** `event-handlers.js` подключён до `storage.js` или `hp-system.js`.
**Решение:** `event-handlers.js` должен быть подключён ПОСЛЕ всех модулей с функциями, которые он вызывает.

### Проблема 5: Броски кубиков не работают
**Причина:** `dice-roller.js` конфликтует с `utils.js`.
**Решение:** `dice-roller.js` независим — проверьте, что он подключён ПОСЛЕ `utils.js`.

### Проблема 6: Данные не сохраняются
**Причина:** `autoSave` вызывается, но `storage.js` не загружен.
**Решение:** Убедитесь, что `storage.js` подключён ДО `event-handlers.js` и `app.js`.

## 🎯 Преимущества рефакторинга

1. **Модульность** — каждый файл отвечает за одну область
2. **Читаемость** — легко найти нужный код
3. **Отладка** — ошибки локализованы в конкретном модуле
4. **Расширяемость** — новые классы/функции добавляются в нужный файл
5. **Параллельная разработка** — разные разработчики работают с разными модулями
6. **Тестирование** — можно тестировать модули по отдельности


## 🔧 ИСПРАВЛЕНИЯ (v1.0.8.4)

### Исправленные ошибки:

1. **❌ Uncaught SyntaxError: '' string literal contains an unescaped line break**
   - **Причина:** Шаблонные строки (template literals) с обратными кавычками `` ` `` конфликтовали при разделении на модули
   - **Решение:** ВСЕ обратные кавычки заменены на обычные строки с конкатенацией (`'строка' + переменная`)
   - **Затронуто:** Все 17 JS-файлов

2. **❌ Загрузка dice-roller.js не удалась**
   - **Причина:** Файл не был скопирован в output
   - **Решение:** Скопирован оригинальный `dice-roller.js` и исправлены обратные кавычки

3. **❌ ReferenceError: getMod is not defined**
   - **Причина:** `utils.js` не был скопирован в output, функция `getMod()` недоступна
   - **Решение:** Скопирован оригинальный `utils.js` и исправлены обратные кавычки

### Правило для будущих изменений:
**НЕ используйте обратные кавычки `` ` `` в JS-файлах!** 
Вместо `${variable}` используйте `'текст' + variable + 'текст'`
