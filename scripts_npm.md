# NPM Scripts Documentation

Этот файл описывает все доступные npm скрипты в проекте D&D Character Sheet.

## Скрипты

### `npm start`
- **Описание**: Запуск веб-сервера приложения
- **Команда**: `node server.js`
- **Применение**: Основной способ запуска приложения. Сервер будет доступен на порту 3000 (или указанном в переменной PORT). Предоставляет API для управления персонажами, расами, классами и заклинаниями, а также статические файлы интерфейса.

### `npm run seed:races`
- **Описание**: Заполнение таблицы `races` начальными данными
- **Команда**: `node seed-races.js`
- **Применение**: Используется для инициализации базы данных расами D&D 5e. Запускается автоматически при первом запуске сервера, если таблица пуста. Можно запустить вручную для повторного заполнения.

### `npm run seed:classes`
- **Описание**: Заполнение таблицы `classes` начальными данными
- **Команда**: `node seed-classes.js`
- **Применение**: Инициализирует базу данных классами персонажей D&D 5e. Автоматически запускается при первом старте сервера. Подходит для ручного перезапуска.

### `npm run seed:spells`
- **Описание**: Заполнение таблицы `spells` базовыми заклинаниями
- **Команда**: `node seed-spells.js`
- **Применение**: Добавляет небольшое количество заклинаний в базу данных. Это устаревший скрипт, заменённый на `seed:spell-data`. Используется только для совместимости.

### `npm run seed:spell-data`
- **Описание**: Полное заполнение данных заклинаний и связей класс-заклинание
- **Команда**: `node seed-spell-data.js`
- **Применение**: Загружает все заклинания из файлов `data/Spells_data/allSpells.js` и `data/Spells_data/ClassSpells.js` в таблицы `spells` и `class_spells`. Создаёт связи между классами и доступными им заклинаниями.
- **Опции**:
  - `--force` или `-f`: Принудительно очищает существующие данные перед загрузкой новых

### `npm run seed:all`
- **Описание**: Запуск всех скриптов инициализации базы данных
- **Команда**: `npm run seed:races && npm run seed:classes && npm run seed:spells`
- **Применение**: Полная инициализация базы данных при первом запуске проекта. Запускает скрипты для рас, классов и базовых заклинаний. Не включает `seed:spell-data`, который нужно запускать отдельно.

## Порядок использования

1. **Первый запуск проекта**:
   ```bash
   npm install
   npm run seed:all
   npm run seed:spell-data
   npm start
   ```

2. **Обновление данных заклинаний**:
   ```bash
   npm run seed:spell-data -- --force
   ```

3. **Перезапуск сервера**:
   ```bash
   npm start
   ```

## Зависимости

Проект использует следующие основные зависимости:
- `sequelize`: ORM для работы с базой данных
- `sqlite3`: Драйвер SQLite базы данных

## Структура базы данных

- `characters`: Персонажи пользователей
- `races`: Расы D&D 5e
- `classes`: Классы персонажей
- `spells`: Заклинания
- `class_spells`: Связи между классами и заклинаниями

Все таблицы создаются автоматически при первом запуске сервера через Sequelize.
