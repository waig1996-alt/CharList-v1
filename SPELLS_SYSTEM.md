# Система Заклинаний (Spells System)

## Обзор

Система заклинаний позволяет персонажу управлять ячейками заклинаний, добавлять различные заклинания и отслеживать их использование. Система поддерживает все классы D&D 5e с автоматическим пересчётом ячеек на основе уровня и типа класса.

## Компоненты системы

### 1. Таблицы ячеек заклинаний (`spell-slots-tables.js`)

Содержит таблицы распределения ячеек заклинаний по уровню персонажа для каждой группы кастеров:

#### Группы кастеров:
- **Полные кастеры** (Бард, Волшебник, Друид, Жрец, Чародей)
  - Используют стандартную таблицу FULL_CASTER_SLOTS
  - Получают ячейки всех уровней (1-9) по мере повышения уровня

- **Полукастеры** (Паладин, Следопыт, Изобретатель)
  - Используют таблицу HALF_CASTER_SLOTS
  - Начинают получать ячейки с 2 уровня персонажа
  - Максимум до 5 уровня заклинаний на уровне 17+

- **Специальные кастеры** (Колдун, Монах)
  - Колдун использует свою таблицу WARLOCK_SLOTS (пакт ячейки, не восстанавливаются при коротком отдыхе)
  - Монах не использует ячейки (может быть расширено)

#### Функции:
```javascript
getSpellSlotsTable(className)        // Получить таблицу для класса
getSpellcasterGroup(className)       // Определить группу кастера
parseSpellSlots(slotsStr)           // Парсить строку ячеек "1/4,2/3,3/2"
getSpellSlotsForClass(className, level) // Получить ячейки для класса/уровня
mergeMulticlassSlots(classes)       // Объединить ячейки при мультиклассе
```

### 2. Состояние приложения (`state.js` обновлено)

```javascript
{
  spells: [],              // Все известные заклинания
  spellSlots: [],          // Ячейки заклинаний {level, max, current}

```

#### Структура заклинания:
```javascript
{
  name: "Магическая ракета",
  level: 1,                // 0 = заговор, 1-9 = уровень заклинания
  action: "action",        // "action", "bonus-action", "reaction", "ritual"
  castTime: "1 действие",  // Время применения
  attr: "int",             // Атрибут для броска (int, wis, cha)
  proficient: false,       // Владение заклинанием
  damage: "1к6+3",         // Урон (опционально)
  description: "текст"     // Описание (опционально)
}
```

#### Структура закреплённого заклинания:
```javascript
{
  name: "Важное заклинание",
  notes: "Описание/заметки для быстрого доступа"
}
```

### 3. Основной модуль (`js/spells.js`)

#### Функции:

##### Управление ячейками
```javascript
initializeSpellSlots(className, classLevel)  // Инициализировать ячейки при добавлении класса
recalculateSpellSlots()                      // Пересчитать ячейки при изменении класса/уровня
renderSlots()                                // Отобразить ячейки в UI
restoreAllSlots()                            // Восстановить все ячейки (долгий отдых)
```

##### Управление заклинаниями
```javascript
addSpell()                   // Добавить новое заклинание через форму
addPinnedSpell()            // Добавить закреплённое заклинание
renderSpells()              // Отобразить все заклинания по уровням
attachSpellEventHandlers()  // Привязать обработчики событий
castSpell(spell)            // Применить заклинание с выбором ячейки
```

##### Загрузка из БД
```javascript
loadSpellsFromDatabase()    // Загрузить заклинания из API
showSpellSelectionModal()   // Показать диалог выбора из БД
selectSpellFromDb(idx, spell) // Выбрать и добавить заклинание из БД
```

## Интеграция с классами

При выборе или изменении уровня класса система автоматически:

1. Определяет группу кастера (полный/полу/особый)
2. Пересчитывает ячейки на основе новых параметров
3. Обновляет UI
4. Сохраняет изменения

### Логика мультикласса

При нескольких кастующих классах:
- Ячейки **объединяются** (суммируются по уровням)
- Колдун может быть в мультиклассе, но его ячейки считаются отдельно
- Смешивание полных и полукастеров работает по стандартным правилам D&D 5e

## Примеры использования

### Добавить заклинание вручную
1. Введите название в поле "Название"
2. Выберите уровень (0 = заговор)
3. Выберите атрибут (INT/WIS/CHA)
4. Введите урон (опционально)
5. Нажмите "📖 добавить"

### Добавить закреплённое заклинание
1. Нажмите "📌 закрепить"
2. Введите название заклинания
3. Добавьте заметки/описание
4. Подтвердите

### Использовать заклинание в бою
1. Нажмите "🎲 Бросок" на карточке заклинания
2. Для заклинаний уровня 1+:
   - Выберите уровень ячейки
   - Если ячейка выше уровня заклинания, урон повысится
3. Нажмите "💥 Урон" для броска урона
4. Ячейка будет потрачена

### Восстановить ячейки
- Нажмите "🔄 Восстановить все" после долгого отдыха
- Это восстановит все ячейки, кроме колдуна (он использует короткий отдых)

## Примечания для разработчиков

### Расширение для других классов
Если нужно добавить новый класс с кастованием:

1. Определите его группу (FULL_CASTER / HALF_CASTER)
2. Добавьте в соответствующий массив классов в `spell-slots-tables.js`
3. Используйте существующую таблицу или создайте новую

### Специальные кастеры
Для создания совершенно новой системы ячеек:

1. Создайте новую таблицу (например, CUSTOM_SLOTS)
2. Добавьте условие в `handleSpecialCasters()`
3. Используйте `getSpellcasterGroup()` для определения

### Интеграция с боевой системой
Броски атак и урона используют:
- `rollD20Unified()` из `roll-engine.js`
- `rollDamageUnified()` из `roll-engine.js`
- `getMod()` для получения модификатора атрибута
